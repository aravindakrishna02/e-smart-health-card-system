# Security Policy

## Scope
This repository currently contains a frontend-only educational prototype and is not suitable for real patient information.

## Reporting a vulnerability
Do not publish real patient information, credentials, tokens, or other secrets in an issue. For a class project, contact the repository maintainer privately through a verified channel.

## Before production use
A production version needs a security review covering authentication, server-side authorization, secure QR-token handling, encryption, private document storage, audit integrity, backups, monitoring, data retention, and applicable healthcare/privacy requirements. The current demo does not implement these controls.
